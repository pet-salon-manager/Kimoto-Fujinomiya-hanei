# ふじのみや旅ナビ

富士宮市の観光スポット案内PWAです。

## この版の内容
- 承認済みの富士山・桜・神社の写真を背景に採用
- 背景はスクロールしても固定表示
- iPhoneホーム画面アイコンも同じ写真ベースに変更
- 各スポットの「詳しく見る」は削除
- 各スポットに「現在地からの行き方」を表示
- Google Mapsで経路案内
- 検索・カテゴリ・お気に入り機能つき

## 反映方法
このフォルダ内のファイルを GitHub リポジトリ
`Kimoto-Fujinomiya-hanei` の main ブランチ直下に上書きアップロードしてください。

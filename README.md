# ふじのみや旅ナビ

提供された富士宮市の観光スポット一覧をもとに作成した、スマートフォン向け観光案内PWAです。

## 主な機能
- スポット検索
- ジャンル別絞り込み
- スポット詳細表示
- Google Mapsで場所を確認
- 現在地からの経路検索
- お気に入り保存（端末内）
- ホーム画面追加対応（PWA）
- 基本画面はオフラインキャッシュ対応

## 起動方法
`index.html` をWebサーバーで配信してください。
PWAとして使う場合は、HTTPS環境に配置してください。

※提供データのうち概略住所や市境付近のスポットは、公開前に公式情報で確認してください。

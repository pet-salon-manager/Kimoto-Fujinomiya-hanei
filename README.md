# ふじのみや旅ナビ 管理者機能版

## 追加した機能
- `admin.html` 管理者画面
- 観光スポットの追加
- 観光スポットの編集
- 観光スポットの削除
- 名称
- ジャンル
- 住所
- エリア
- 電話番号
- ホームページ
- 細かい説明文
- 写真URL / 写真アップロード
- 緯度・経度
- 表示順
- 公開 / 非公開

## 保存方式
- Supabase未設定: この端末のブラウザ内へ保存
- Supabase設定済み: クラウドへ保存し、公開サイトの全利用者へ反映

Supabase接続方法は `SUPABASE_SETUP.md` を参照してください。

管理者画面:
`/admin.html`


## 今回の更新
- 管理者画面で住所を入力して保存すると、緯度・経度が空欄の場合は自動取得
- 個別の「住所から緯度経度を取得」ボタンを追加
- 既存スポット向け「住所から緯度経度を一括取得」ボタンを追加
- 公開画面の地図・経路案内は、緯度経度が登録済みなら座標を優先
- 登録写真を観光スポットカード内に大きく表示
